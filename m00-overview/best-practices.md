# Best Practices für die Einführung von Microsoft 365 Copilot

| Regel | Warum | Lab |
| --- | --- | --- |
| Berechtigungen vor der ersten Lizenz prüfen | Copilot findet alles, was eine Person öffnen darf; zu weite Freigaben werden sofort sichtbar | 1.1, 3.1 |
| Kontext bereitstellen statt Modell wechseln | Die Qualität hängt stärker an Dateien, Ablage und Auftrag als am Modell | 1.2 |
| Dateien referenzieren statt beschreiben | Frei beschriebene Fakten füllt das Modell mit Plausiblem auf | 1.2 |
| Jedes Ergebnis vor der Weitergabe prüfen | Sprachmodelle formulieren auch Falsches überzeugend | 1.2, 3.1 |
| Mit einem Agenten für wiederkehrende Fragen starten | klarer Nutzen, freigegebenes Wissen, geringes Risiko | 2.1, 2.4 |
| Erfahrungswissen als Markdown festhalten | anbieterunabhängig, versionierbar, für Mensch und KI lesbar | 2.2 |
| Für jeden Agenten, Skill und jede Anbindung einen Owner benennen | ohne Owner veralten Wissen und Regeln unbemerkt | 2.2, 3.1 |
| Fachsysteme zuerst nur lesend anbinden | Schreibender Zugriff hat Folgen im System; erst nach Erfahrung und Freigabe | 2.3 |
| Erfolgskriterium vor dem Start festlegen | Ohne Vorher-Wert lässt sich der Nutzen nach dem Pilot nicht belegen | 2.4 |
| Schatten-KI mit einem freigegebenen Angebot beantworten | Verbote ohne Alternative verlagern die Nutzung ins Private | 3.1 |
| Datenschutzbeauftragte früh beteiligen | DSFA, Verzeichnis und Aufbewahrung brauchen Vorlauf | 3.2 |
| Mitarbeitervertretung vor dem Pilot einbinden | Mitbestimmung gilt schon für den Test; spätes Einbinden kostet Vertrauen und Zeit | 3.3 |
| Einwände ernst nehmen und ehrlich beantworten | beschwichtigende Antworten erzeugen Misstrauen | 4.1 |
| Rollenbasiert schulen | Vertrieb, HR und Controlling brauchen unterschiedliche Beispiele; Art. 4 EU AI Act verlangt KI-Kompetenz | 4.1 |
| Pilotgruppe gemischt zusammensetzen | nur IT oder nur Begeisterte liefern kein belastbares Bild | 4.2 |
| In Ausbaustufen planen | erst Apps, dann ein Agent, dann eine Anbindung; jede Stufe auf der vorigen aufbauen | 4.2 |
