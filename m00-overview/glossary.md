# Glossar

| Begriff | Bedeutung | Lab |
| --- | --- | --- |
| Agent | gespeicherter Spezialassistent mit festen Anweisungen, Wissen und ggf. Werkzeugen | 2.1 |
| Agent Builder | Bereich in Copilot Chat, in dem ein Agent ohne Code angelegt, getestet und geteilt wird | 2.1 |
| Antwortlinie | abgestimmte, ehrliche Kernantwort auf einen wiederkehrenden Einwand | 4.1 |
| Anweisungen | Text, der einem Agenten Rolle, Aufgabe, Ton und Grenzen vorgibt | 2.1 |
| Anwendungsfall | konkrete, wiederkehrende Aufgabe mit Nutzergruppe und Kontext | 2.4 |
| Arbeitsmodus | Einstellung in Copilot Chat, in der zusätzlich die Arbeitsdaten über Microsoft Graph genutzt werden | 1.2 |
| Auftragsverarbeitung | Dienstleister verarbeitet Daten im Auftrag des Verantwortlichen; Vertrag nach Art. 28 DSGVO | 3.2 |
| Ausbaustufe | Apps, eigener Agent oder Anbindung eines Fachsystems | 2.4 |
| Berechtigung | Recht einer Person, eine Mail, Datei oder einen Ordner zu öffnen | 1.1 |
| besondere Kategorien | besonders geschützte Daten wie Gesundheit oder Religion (Art. 9 DSGVO) | 3.2 |
| Betriebsrat | Mitarbeitervertretung in der Privatwirtschaft (BetrVG) | 3.3 |
| Betriebs- / Dienstvereinbarung | verbindlicher Vertrag zwischen Arbeitgeber und Mitarbeitervertretung | 3.3 |
| Bewertungsmatrix | Tabelle, die Fälle auf denselben Achsen mit 1 bis 3 bewertet | 2.4 |
| Champion | Person im Fachbereich, die das Werkzeug früh nutzt und anderen hilft | 4.1 |
| Change Management | geplante Begleitung einer Veränderung | 4.1 |
| Cloud-Modell | KI-Modell, das im Rechenzentrum eines Anbieters läuft | 2.3 |
| Copilot Chat | KI-Chat für Microsoft-365-Konten ohne Zusatzlizenz, ohne Zugriff auf Arbeitsdaten | 1.1 |
| Datenschutzbeauftragte | berät und prüft Verarbeitungen, entscheidet nicht anstelle der Leitung | 3.2 |
| Datenschutz-Folgenabschätzung (DSFA) | dokumentierte Vorab-Prüfung bei voraussichtlich hohem Risiko (Art. 35 DSGVO) | 3.2 |
| Einigungsstelle | Schlichtungsgremium bei fehlender Einigung mit dem Betriebsrat | 3.3 |
| Erfolgskriterium | messbare Aussage mit Vorher-Wert, Zielwert und Frist | 2.4 |
| EU AI Act | EU-Verordnung über künstliche Intelligenz (2024/1689) | 3.2 |
| EU-Datengrenze | Zusage von Microsoft, Daten von EU-Kunden in der EU zu speichern und zu verarbeiten | 1.1 |
| Fachsystem | Software außerhalb von Microsoft 365, z. B. CRM, ERP, Ticketsystem | 2.3 |
| Hochrisiko | Einstufung im EU AI Act für KI in sensiblen Bereichen, z. B. Bewerberauswahl | 3.2 |
| KI baut KI | KI-Assistenten erarbeiten Problem, Konzept und Anleitung für einen anderen Agenten | 2.2 |
| KI-Kompetenz | ausreichendes Wissen für den sachkundigen Einsatz von KI (Art. 4 EU AI Act) | 3.2 |
| KI-Richtlinie | internes Regelwerk zu erlaubten Werkzeugen, tabu-Daten, Prüfpflicht, Meldeweg | 3.1 |
| Konnektor | Microsoft-Weg, Inhalte eines Fremdsystems durchsuchbar zu machen (nur lesend) | 2.3 |
| Kontext | alles, was das Sprachmodell zusätzlich zur Frage erhält | 1.2 |
| lokales Modell | KI-Modell auf eigenen Servern; Daten verlassen das Haus nicht | 2.3 |
| Markdown | einfaches Textformat (`.md`) mit `#` für Überschriften und `-` für Listen | 2.2 |
| MCP (Model Context Protocol) | offener Standard, über den KI-Assistenten mit Fachsystemen sprechen | 2.3 |
| MCP-Client / MCP-Server | Teil des KI-Werkzeugs bzw. Programm vor einem Fachsystem, die über MCP verbunden sind | 2.3 |
| Memory | Copilot merkt sich Vorlieben und Fakten einer Person; einsehbar und löschbar | 1.2 |
| Microsoft 365 Copilot | Zusatzlizenz: Copilot in den Apps mit Zugriff auf die eigenen Arbeitsdaten | 1.1 |
| Microsoft Graph | Schnittstelle, über die Copilot Microsoft-365-Daten mit den Rechten der Person findet | 1.1 |
| Mitbestimmung | Recht der Mitarbeitervertretung, gleichberechtigt mitzuentscheiden | 3.3 |
| Oversharing | Dateien sind für mehr Personen freigegeben als nötig | 3.1 |
| Owner | benannte Person, die einen Agenten, Skill oder eine Anbindung verantwortet | 2.2 |
| Personalrat | Mitarbeitervertretung im öffentlichen Dienst (BPersVG, Landesgesetze) | 3.3 |
| Pilot / Pilotgruppe | befristeter Test mit einer kleinen Gruppe vor der Entscheidung für alle | 4.2 |
| Pilotvereinbarung | befristete Vereinbarung mit der Mitarbeitervertretung für die Testphase | 3.3 |
| Prompt | Eingabe oder Auftrag an Copilot, gilt für eine Anfrage | 1.1 |
| Prüfpflicht | KI-Ergebnisse werden vor Weitergabe von einem Menschen geprüft | 3.1 |
| Readiness | organisatorische und technische Voraussetzungen sind erfüllt | 4.2 |
| Risikomatrix | Einordnung von Risiken nach Wahrscheinlichkeit und Auswirkung | 3.1 |
| Schatten-KI | KI-Werkzeuge ohne Freigabe der Organisation, z. B. private Chat-Konten | 3.1 |
| Skill | Markdown-Datei `SKILL.md` mit einer Anleitung, die ein Agent bei Bedarf lädt | 2.2 |
| Sponsor | Mitglied der Leitung, das die Einführung verantwortet | 4.2 |
| Sprachmodell | KI, die aus vielen Texten gelernt hat und plausible Fortsetzungen erzeugt | 1.1 |
| Tenant | die Microsoft-365-Umgebung einer Organisation | 1.1 |
| Verzeichnis der Verarbeitungstätigkeiten | interne Liste aller Datenverarbeitungen (Art. 30 DSGVO) | 3.2 |
| Vertraulichkeitskennzeichnung | Markierung wie „intern" oder „vertraulich", an die Schutzregeln geknüpft werden | 3.1 |
| Wissensdatei | Datei mit Fakten oder Regeln, die ein Agent als Wissen durchsucht | 2.2 |
