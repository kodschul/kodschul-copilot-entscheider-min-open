# Microsoft 365 Copilot für Entscheider – Potenziale, Risiken und Einführung steuern

**½-Tag-Workshop** · Office/Business · Deutsch

</div>

---

Teilnehmerunterlagen des Kurses **„Microsoft 365 Copilot für Entscheider – Potenziale, Risiken und Einführung steuern“**. Die fiktive Beratung **Nordwind Consulting** muss entscheiden, ob und wie Copilot eingeführt wird; der Kurs begleitet diese Entscheidung von „Was ist das?“ bis zum 90-Tage-Plan.

Jedes Lab besteht aus drei Dateien: Theorie (`-thx.md`), Übung (`-exc.md`) und Lösung (`-sol.md`). Alle Pfade in dieser Datei sind relativ zu diesem Ordner.

## Auf einen Blick

| | |
| --- | --- |

| **Sprache** | Deutsch |
| **Szenario** | Nordwind Consulting (fiktiv); Ergebnis: geprüfte Entscheidungsvorlage mit 90-Tage-Plan |

## Projektdateien

Alle Projektdateien liegen in [`project/`](project/). Herzstück ist die vorbefüllte [Entscheidungsvorlage](project/nordwind-entscheidungsvorlage.md): Jede Übung prüft und korrigiert einen Abschnitt, die Lösung nennt die Schwächen des Entwurfs und eine korrigierte Fassung. Dazu kommen Ausgangslage, Fallgalerie, Bewertungsmatrix, Checklisten und die Demo-Dateien; die Zuordnung Abschnitt → Lab steht in [`project/README.md`](project/README.md).
