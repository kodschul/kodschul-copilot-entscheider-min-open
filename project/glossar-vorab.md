# Vorab-Glossar: 14 Begriffe für Entscheider

Eine Seite zum Einlesen vor dem Kurs. Jeder Begriff wird im Kurs noch einmal erklärt; das Glossar ist keine Voraussetzung.

| Begriff | Bedeutung in einem Satz | Im Kurs |
| --- | --- | --- |
| Sprachmodell | KI, die aus sehr vielen Texten gelernt hat, das wahrscheinlich passende nächste Wort zu bilden, und dadurch Texte versteht und schreibt. | Lab 1.1 |
| Microsoft 365 Copilot | KI-Assistent in Outlook, Teams, Word, PowerPoint und Excel, der mit den Mails, Chats und Dateien der jeweiligen Person arbeitet. | Lab 1.1 |
| Copilot Chat | Chat-Assistent in Microsoft 365; ohne Zusatzlizenz ohne Zugriff auf die eigenen Arbeitsdaten. | Lab 1.1 |
| Microsoft Graph | die Schicht, über die Copilot auf Mails, Kalender, Chats und Dateien zugreift, immer mit den Berechtigungen der jeweiligen Person. | Lab 1.1 |
| Kontext | alles, was die KI zusätzlich zur Frage bekommt: Dateien, Mails, Besprechungen, Regeln, Fachsysteme. | Lab 1.2 |
| Memory | Funktion, mit der sich Copilot Vorlieben und Fakten einer Person merkt; einsehbar und löschbar. | Lab 1.2 |
| Agent | gespeicherter Spezialassistent mit festen Anweisungen, eigenem Wissen und Werkzeugen für eine bestimmte Aufgabe. | Lab 2.1 |
| Markdown | einfaches Textformat mit Überschriften und Listen, das Menschen und KI gleichermaßen lesen. | Lab 2.2 |
| Skill | Markdown-Datei mit einer Anleitung für eine abgegrenzte Aufgabe, die ein Agent bei Bedarf lädt. | Lab 2.2 |
| MCP (Model Context Protocol) | offener Standard, über den KI-Agenten an andere Systeme angeschlossen werden, um dort zu lesen oder zu handeln. | Lab 2.3 |
| Lokales KI-Modell | Sprachmodell, das auf eigenen Servern läuft, sodass Daten das Haus nicht verlassen. | Lab 2.3 |
| Oversharing | Dateien sind für mehr Personen freigegeben als nötig; Copilot macht sie dadurch leicht auffindbar. | Lab 3.1 |
| DSFA | Datenschutz-Folgenabschätzung: vorab dokumentierte Prüfung der Risiken einer Datenverarbeitung für die Betroffenen. | Lab 3.2 |
| Mitbestimmung | Recht des Betriebs- oder Personalrats, bei der Einführung bestimmter Technik mitzuentscheiden. | Lab 3.3 |
