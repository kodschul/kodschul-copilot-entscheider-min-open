# Readiness-Checkliste vor der ersten Lizenz

Vorlage für Lab 4.2. Jeder Punkt ist vor dem Pilotstart erledigt oder bewusst mit Begründung zurückgestellt.

| # | Bereich | Prüffrage | Erledigt? |
| -: | --- | --- | --- |
| 1 | Berechtigungen | Sind Ordner mit „alle Mitarbeitenden"-Freigabe geprüft, besonders Kalkulationen, HR- und Finanzdaten? | |
| 2 | Ablage | Liegen die für den Pilot wichtigen Dokumente in SharePoint/OneDrive, aktuell und eindeutig benannt? | |
| 3 | Vertraulichkeit | Sind besonders schützenswerte Dokumente gekennzeichnet? | |
| 4 | Richtlinie | Liegt eine KI-Richtlinie in einfacher Sprache vor? | |
| 5 | Mitarbeitervertretung | Ist der Betriebs- oder Personalrat eingebunden und eine (vorläufige) Vereinbarung abgeschlossen? | |
| 6 | Datenschutz | Sind die Punkte der [Compliance-Checkliste](compliance-checkliste.md) geklärt? | |
| 7 | Schulung | Gibt es eine rollenbasierte Schulung für die Pilotgruppe? | |
| 8 | Support | Wer beantwortet Fragen im Pilot (Champions, Kanal)? | |
| 9 | Agenten und Skills | Wer darf Agenten bauen, teilen und freigeben; wer pflegt Skill-Dateien? | |
| 10 | Anbindungen | Welche Fachsysteme sind angebunden, nur lesend oder auch schreibend, mit benanntem Owner? | |
| 11 | Erfolgsmessung | Sind Vorher-Wert, Zielwert und Frist des Erfolgskriteriums festgelegt? | |
| 12 | Kommunikation | Ist das „Warum" an alle Mitarbeitenden kommuniziert, nicht nur an die Pilotgruppe? | |
