# Compliance-Checkliste für die Einführung von Microsoft 365 Copilot

Vorlage für Lab 3.2. Keine Rechtsberatung; jeder Punkt wird mit der eigenen Datenschutz- und Rechtsabteilung geklärt. Stand: 31.10.2026, vor Verwendung prüfen.

| # | Punkt | Worum es geht | Status (vorhanden / fehlt / unklar) | Verantwortlich |
| -: | --- | --- | --- | --- |
| 1 | Auftragsverarbeitung | Vertrag mit Microsoft über die Verarbeitung personenbezogener Daten (Art. 28 DSGVO) liegt vor und deckt Copilot ab | | Datenschutz |
| 2 | Verzeichnis der Verarbeitungstätigkeiten | Copilot als Verarbeitung mit Zweck, Datenarten und Betroffenen eingetragen (Art. 30 DSGVO) | | Datenschutz |
| 3 | Datenschutz-Folgenabschätzung | geprüft, ob eine DSFA nötig ist (Art. 35 DSGVO), Ergebnis dokumentiert | | Datenschutz |
| 4 | Aufbewahrung und Löschung | Regeln für Copilot-Interaktionen und Memory festgelegt | | IT, Datenschutz |
| 5 | KI-Kompetenz | Schulung der Mitarbeitenden geplant, die KI nutzen (Art. 4 EU AI Act, gilt seit 02.02.2025) | | HR |
| 6 | KI-Richtlinie | erlaubte Werkzeuge, verbotene Nutzungen (z. B. besonders sensible Daten nach Art. 9 DSGVO, Bewertung von Personen), Prüfpflicht, Meldeweg | | Geschäftsführung |

## Zusatzpunkte bei Agenten und Anbindungen

| Punkt | Worum es geht |
| --- | --- |
| Datenflüsse über angebundene Systeme | welche Daten ein Agent aus Fachsystemen liest und wohin sie fließen |
| Externe MCP-Server | wer den Server betreibt und ob dafür ein eigener Auftragsverarbeitungsvertrag nötig ist |
| Agenten mit Personenbezug | Agenten, die über Personen Auskunft geben oder Entscheidungen über Personen vorbereiten, brauchen eine gesonderte Prüfung (Hochrisiko-Bereiche nach EU AI Act, z. B. Bewerberauswahl) |
